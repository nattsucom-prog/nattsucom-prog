# nattsucom-prog

自宅の Synology NAS(DS220+) と Claude Code を中心に、音声・Web・組み込みまわりの個人プロジェクトを作っています。
ずんだもん(VOICEVOX)を使った音声まわりの遊びが多め。なんちゃってエンジニアです。

## 🎙️ ずんだもん / 音声

- [voicevox-nas](https://github.com/nattsucom-prog/voicevox-nas) - VOICEVOX ENGINE + キャッシュ層付き/speak API (Python, Flask, Docker)
- [zundamon-speaker](https://github.com/nattsucom-prog/zundamon-speaker) - 定型文ボタン＋自由入力でずんだもんを喋らせるWeb UI (HTML/CSS/JS)
- [switchbot-alert](https://github.com/nattsucom-prog/switchbot-alert) - 冷凍庫温度異常をずんだもん音声で通知 (PHP, SwitchBot API)

## 🎮 子供向けWebアプリ

- [nori-poke-quiz](https://github.com/nattsucom-prog/nori-poke-quiz) - のりもの・ポケモンクイズ (PHP)

## 🔧 ハードウェア

- [pico-projects](https://github.com/nattsucom-prog/pico-projects) - 株価・天気・センサー表示ダッシュボード (Raspberry Pi Pico 2W, ESP32-S3, Python/MicroPython)

## 🎉 遊び心系Webアプリ

- [myapp](https://github.com/nattsucom-prog/myapp) - 言い訳ジェネレーター(状況×トーンでランダム生成) (JavaScript)
